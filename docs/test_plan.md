# План тестирования

| № | Проверка | Ожидаемый результат |
|---|---|---|
| 1 | Бэклог сортируется по приоритету | high, medium, low |
| 2 | Полный цикл спринта | задача в «Готово», скорость равна её оценке |
| 3 | Второй спринт при открытом первом | сообщение об ошибке |
| 4 | Неизвестный приоритет | сообщение об ошибке |
| 5 | Пустое название задачи | сообщение об ошибке |
| 6 | Выполненная задача берётся в новый спринт | сообщение об ошибке, скорость не меняется |
| 7 | Смена статуса задачи закрытого спринта | сообщение об ошибке, скорость не меняется |

Модульные тесты: `python -m unittest`.
