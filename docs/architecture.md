# Архитектура

Программа состоит из четырёх модулей пакета `agile_planner`:

- `models.py` — классы данных `Task` и `Sprint`, списки статусов и приоритетов;
- `storage.py` — чтение и запись данных в файл JSON;
- `planner.py` — класс `Planner` с операциями над бэклогом, спринтами и доской;
- `cli.py` — разбор аргументов командной строки и вывод результатов.

Зависимости направлены в одну сторону: `cli` -> `planner`, `storage` -> `models`.
Модуль `planner` не работает с файлами, поэтому его можно проверять
модульными тестами без диска.

Жизненный цикл задачи: бэклог -> к выполнению -> в работе -> готово.
При закрытии спринта незавершённые задачи возвращаются в бэклог.
