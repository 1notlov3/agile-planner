# Техническое задание (кратко)

Составлено по разделам ГОСТ 19.201-78.

## 1. Введение
Наименование: «Личный Agile-планировщик». Область применения: планирование
личных и учебных задач одним пользователем на персональном компьютере.

## 2. Основания для разработки
Задание по дисциплине «Проектная деятельность в ИТ», направление 09.03.03
«Прикладная информатика». Наименование темы разработки: «Разработка программы
планировщика Agile для личного пользования».

## 3. Назначение разработки
Функциональное: ведение бэклога, планирование спринтов, отслеживание статусов
задач на доске, расчёт скорости выполнения.
Эксплуатационное: замена бумажных списков и громоздких командных трекеров
для одного пользователя.

## 4. Требования к программе
4.1. Функции: добавление задачи с оценкой (story points) и приоритетом; вывод
бэклога по приоритету; начало и закрытие спринта; перенос задачи в спринт;
смена статуса (К выполнению, В работе, Готово); вывод доски; расчёт скорости.
4.2. Надёжность: при ошибочном вводе программа выводит сообщение и не теряет
данные.
4.3. Условия эксплуатации: Windows 10/11, Linux или macOS, Python 3.10+.
4.4. Хранение данных: файл JSON в домашнем каталоге пользователя.

## 5. Требования к документации
README с инструкцией по запуску, комментарии в исходном коде.
