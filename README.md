# Личный Agile-планировщик

Консольная программа для планирования личных задач по принципам Agile:
бэклог с приоритетами и оценками в story points, спринты фиксированной
длительности, канбан-доска и расчёт скорости.

Учебный проект по дисциплине «Проектная деятельность в ИТ».
Автор: Грачев Максим, группа о.ИЗДтс 23.1/БЗ-25.

## Запуск

Нужен Python 3.10 или новее, сторонние библиотеки не используются.

```
python main.py add "Подготовить отчёт" -p 3 --priority high
python main.py backlog
python main.py sprint "Сдать отчёт" -d 7
python main.py plan 1
python main.py move 1 in_progress
python main.py board
python main.py close
```

Данные хранятся в файле `~/.agile_planner.json`.

## Тесты

```
python -m unittest
```
